#### Example Request (verified 2026-11)
* Makes a user playlist private.
##### Method
```PUT```
##### Url
```https://api.tidal.com/v2/playlists/{uuid}/set-private?countryCode={country}```
##### Header
```authorization: Bearer {access_token}```\
```x-tidal-client-version: {version}```
#### Example Response

```200 OK``` (empty body)
